# Гамбит — шахматный помощник

Мобильное шахматное приложение с тренером: играете партию, а приложение
подсказывает сильнейший ход и **объясняет по-русски, почему он хорош**.

Оригинальное приложение: название, оформление (собственная палитра и иконка),
тексты и весь код — свои. Каждая подсказка — это разбор мотива (вилка,
связка, выигрыш материала, развитие, борьба за центр), а не просто
«сходите сюда».

## Что умеет

| Возможность | Где |
|---|---|
| Игра с ботом (3 уровня) или за двоих | Настройки → Соперник |
| **Подсказка**: лучший ход + стрелка на доске + объяснение | кнопка «Подсказка» или клавиша `H` |
| Разбор идеи хода: вилка, связка, шах, мат, выигрыш фигуры | карточка «Тренер» |
| Предупреждение о зевках после вашего хода | включается в настройках |
| «Угрозы соперника» — что он может сделать в ответ | кнопка в карточке тренера |
| Оценка позиции, график, три лучших варианта | карточка «Оценка» |
| Разбор партии: точность, ошибки, лучший ход в каждой позиции | вкладка «Разбор» |
| Задачи-тренировки с проверкой ответа | вкладка «Задачи» |
| Часы, нотация, PGN, FEN, отмена ходов, просмотр истории | интерфейс |
| Офлайн-работа (PWA), установка на домашний экран | манифест + service worker |

## Запуск

```bash
npm start          # http://localhost:4173
npm test           # тесты движка и тренера (23 проверки)
```

Никаких зависимостей и сборки нет — проект работает как есть
(ES-модули + собственный движок).

## Устройство

```
index.html          интерфейс
src/app.js          логика экрана, бот, подсказки, разбор
src/board-ui.js     доска: тапы, перетаскивание, анимация, стрелки
src/coach.js        тренер: объяснения, мотивы, угрозы, оценка хода
src/engine/core.js  правила и генерация ходов (0x88), проверено perft
src/engine/search.js альфа-бета + TT + quiescence + PVS (~300 тыс. поз./с)
src/engine/eval.js  оценка: материал, PST, пешечная структура, мобильность
vendor/chess.js     эталонные правила/SAN (MIT, используется как арбитр)
assets/pieces/      фигуры для доски
android/            Android-проект (WebView-обёртка), см. android/README.md
tests/run.mjs       тесты
```

Движок собственный: `chess.js` применяется только как арбитр правил и
для нотации SAN, поэтому поиск можно менять независимо.

## Android
